# Contributing

This is a competition project, so active development has ended. That said, feedback and discussion are welcome.

## Reporting Issues

If you find a bug or have a question, open an issue with a clear description and steps to reproduce.

## Pull Requests

PRs are welcome for:
- Bug fixes in the core pipeline (`factor.py`, `train.py`, `predict_v7.py`)
- Documentation improvements
- Code clarity improvements

Please keep PRs focused and small. For larger changes, open an issue first to discuss.

## Code Style

- Follow existing code conventions
- Add docstrings for new functions
- Keep Numba-accelerated functions in `factor.py` pure (no Python objects)
