1. factor.py — 特征生成

必须定义且仅定义以下函数：

import numpy as np

def generate_factors(dataset_name: str, data: np.ndarray) -> np.ndarray:
    ...
    return factors  # np.ndarray, shape (T, F), dtype float32

系统会对每个 dataset 调用一次这个函数。你不需要自己读写文件，框架负责全部 I/O。

无状态要求：你的模块在每个 dataset 调用前都会重新加载。不要依赖全局变量、缓存或任何跨调用保留的状态 — 它们在 reload 后不会保留。

参数：

  • dataset_name — 匿名数据集 ID，如 "dataset0", "dataset1", ..., "dataset29"
  • data — np.ndarray, shape (T, 5), dtype float32
    列顺序: [open, high, low, close, volume]

返回值：

  • np.ndarray, shape (T, F), dtype float32
  • F = 你计算的特征数量，最多 512
  • 缺失/无效位置允许填 NaN
  • T 必须与输入完全一致

2. predict.py — 信号生成

必须定义且仅定义以下函数：

import numpy as np

def generate_signals(dataset_name: str, factors: np.ndarray) -> np.ndarray:
    ...
    return signals  # np.ndarray, shape (T, 2), dtype float32

这里是你加载模型、执行推理的地方。你可以自由决定如何使用特征 — 滑动窗口、直接输入、特征工程、多模型 ensemble 等都可以。

参数：

  • dataset_name — 与 factor.py 中相同的匿名数据集 ID
  • factors — np.ndarray, shape (T, F), dtype float32
    你的 factor.py 为该 dataset 返回的特征

返回值：

  • np.ndarray, shape (T, 2), dtype float32
  • 列 0 = Ret5（5-bar 前瞻收益，见下方数据说明）的预测信号
  • 列 1 = Ret60（60-bar 前瞻收益，见下方数据说明）的预测信号
  • 允许填 NaN / Inf，评估时会将 invalid 值替换为 0 后仍参与 IC 计算（详见下方 "IC 指标定义"）
  • T 必须与输入完全一致

最简示例

factor.py:

import numpy as np

def generate_factors(dataset_name: str, data: np.ndarray) -> np.ndarray:
    # data 列: [open, high, low, close, volume]
    open_  = data[:, 0]
    close  = data[:, 3]
    volume = data[:, 4]

    momentum = close / np.where(open_ == 0, np.nan, open_) - 1
    log_vol  = np.log1p(volume)

    return np.stack([momentum, log_vol], axis=1)  # (T, 2)

predict.py:

import numpy as np

def generate_signals(dataset_name: str, factors: np.ndarray) -> np.ndarray:
    T = factors.shape[0]
    # 最简 baseline：直接用第一列特征作为 Ret5 和 Ret60 的信号
    sig = factors[:, 0] if factors.shape[1] > 0 else np.zeros(T)
    return np.stack([sig, sig], axis=1)  # (T, 2)

IC 指标定义

本赛题使用的 IC（Information Coefficient）指标，定义为 同一样本集合上的预测信号与真实收益之间的 Pearson 相关系数。 给定某个 dataset、某个标签 y ∈ {Ret5, Ret60}、以及某个样本子集（normal 或 extreme）， 记对应行上的预测向量为 p = (p1, …, pn)，真实收益向量为 y = (y1, …, yn)，其均值为 p̄、ȳ，则： 

            Σᵢ (pᵢ − p̄)(yᵢ − ȳ)
IC(p, y) = ───────────────────────────────────────────────
           √( Σᵢ (pᵢ − p̄)² · Σᵢ (yᵢ − ȳ)² )

具体计算约定：

  • Invalid 值处理：任一位置出现 NaN / ±Inf（预测或真实收益任一侧）时，该位置会被替换为 0 后仍然参与计算，不会被剔除。也就是说，missing 的预测被当作"零信号"，同时该样本也会被算入均值 p̄、ȳ 与方差项里。因此，请尽量保证你的预测是有限数；把全段信号填 NaN 并不等同于"跳过该段"。
  • 若样本数 n < 2，或替换后的分母为 0（预测全为同一常数、或真实收益全为同一常数），该 IC 记作 NaN。
  • IC 在每个 dataset 上独立计算；不同 dataset 的预测与收益不跨集合合并，避免尺度差异污染结果。
  • 对每个 dataset 分别报告 4 个 IC：normal × Ret5、normal × Ret60、extreme × Ret5、extreme × Ret60。其中 extreme 子集 = 落入 extreme_intervals 任意闭区间内的行，normal 子集 = 其余行。
  • IC 取值范围为 [−1, 1]，绝对值越大表示预测与真实收益线性相关性越强；正负号由预测信号自身方向决定。

参考实现（与评测服务器逻辑一致）：

import numpy as np

def pearson_ic(predictions: np.ndarray, labels: np.ndarray) -> float:
    if predictions.shape[0] < 2:
        return float("nan")
    # Invalid → 0，然后整体参与相关系数计算
    p = np.nan_to_num(predictions.astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
    l = np.nan_to_num(labels.astype(np.float64),      nan=0.0, posinf=0.0, neginf=0.0)
    p = p - p.mean()
    l = l - l.mean()
    denom = np.sqrt((p**2).sum() * (l**2).sum())
    if denom == 0:
        return float("nan")
    return float((p * l).sum() / denom)
